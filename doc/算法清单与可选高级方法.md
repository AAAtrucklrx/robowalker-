# 算法清单与可选高级方法

> 用途：报告"算法选型"章节的素材，也可作为答辩时的知识地图。
> 分两部分：**一、已经在用**（附代码位置）；**二、可以升级的高级方法**（附代价与适用时机）。

---

# 一、已经在用的算法

## 1. IMU 协议逆向（数据驱动，无手册）

| 方法 | 做什么 | 代码 |
|---|---|---|
| 同步字搜索 + 间隔直方图 | 找帧头、定帧长（`5A A5`→82 字节，4996/5002 一致） | `imu_h7.py` |
| 零填充自相关 | 用"填充字节"的周期性定位帧长（比全字节自相关信噪比高） | 逆向阶段 |
| 浮点假设检验 | 按 float32 解出来的模长≈9.8 → 判定为加速度；按 deg/s 解释不合理 → 判定为 rad/s | 逆向阶段 |
| 单调性检验 | 某字段逐帧 +1 → 判定为毫秒时间戳 | `imu_h7.py` |
| **四元数↔欧拉角交叉验证** | 用四元数算欧拉角，与板子自带字段比对，误差 2.4e-7 rad → 同时确认字段语义与 (w,x,y,z) 顺序 | `imu_h7.validate()` |

> 这一节的价值在于**方法论**：每一步都是独立证据，互相印证，而不是"猜对了"。

## 2. 标定板检测

| 方法 | 原理 | 备注 |
|---|---|---|
| **`findChessboardCornersSB`** | 基于扇区（sector-based）的检测器，自带亚像素精度，对噪声/模糊/畸变鲁棒 | 首选 |
| 经典 `findChessboardCorners` + **`cornerSubPix`** | 粗检测后用迭代法做亚像素细化（鞍点拟合） | 回退路径 |
| ChArUco (`CharucoDetector` / `interpolateCornersCharuco`) | 方格 + ArUco，**部分出画或局部遮挡仍可检测**，容错比纯棋盘格高得多 | `target_detect.py` |

## 3. PnP（位姿求解）

| 方法 | 原理 |
|---|---|
| **`SOLVEPNP_IPPE`** | 平面目标的**解析闭式解**（Infinity Point based Pose Estimation），会给出**两个候选** |
| **`solvePnPRefineLM`** | Levenberg-Marquardt 迭代细化。IPPE 是无细化闭式解，精度不够（实测残差能从 0.6° 涨到 8.9°） |
| **平面二义性消解** | 两个分支各自 LM 细化后，按"板面朝向相机（`R[2,2]<0`）+ 深度为正 + 时间连续"选。**不做这步会让相机轨迹整体翻转** |

## 4. C1 相机内参

| 方法 | 原理 |
|---|---|
| **张正友平面标定法** | 每个姿态的单应矩阵 → 由"旋转列正交且等长"约束解出内参闭式初值 → 全局 LM 细化（`cv2.calibrateCamera`） |
| **Brown-Conrady 畸变模型** | 径向 `k1 r² + k2 r⁴ + k3 r⁶` + 切向 `p1, p2`（OpenCV 的 `plumb_bob`） |
| **train/val 分离** | 标定只用 train，val 上**只用 K/dist** 靠 `solvePnP` 重估位姿再算重投影误差。**不用标定数据自证** |
| 可选约束 | `CALIB_FIX_PRINCIPAL_POINT` / `CALIB_FIX_ASPECT_RATIO` / `CALIB_FIX_K3`（弱可观测时固定） |

## 5. C2 时间对齐（本项目自研，非现成库）

| 方法 | 原理 |
|---|---|
| **转动角度匹配** | 由 `R_IC·ΔR_cam = ΔR_imu·R_IC`，两个相对旋转**相似** → 迹相同 → **旋转角必然相等**。用"角度"匹配就**不需要预知外参**，可以先解 τ 再解外参 |
| **10 kHz 重采样 + 累积梯形积分** | 直接对窗口内原始样本积分会让边界吸附到 1 kHz 采样点、代价函数随 τ 变**阶梯状**，抛物线细化失效。重采样后 τ 量化误差降到 0.1 ms |
| 一维网格搜索 + **抛物线插值细化** | 先粗定位到步长内，再用最优点的左右邻居拟合二次曲线求亚步长极值 |
| 旋转角用**迹公式** | `θ = arccos((tr(R)−1)/2)`，比 `log(R)` 数值更稳 |
| **姿态积分（零阶保持）** | `R ← R·exp([ω]Δt)`，1 kHz 下足够准；无磁力计 → yaw 不可观测，只适合短窗 |

## 6. IMU 预处理

| 方法 | 原理 |
|---|---|
| **滑窗标准差静止检测** | 加速度与陀螺在滑窗内标准差同时低于阈值 → 判为静止段 |
| **零偏标定** | 陀螺零偏 = 静止段均值；加速度零偏 = 均值 − 重力方向×9.80665 |
| 重力对齐 | 由静止段加速度均值确定 IMU 系下的"上"方向 |

## 7. C3 旋转外参（手眼标定 AX = XB）

| 方法 | 原理 | 归属 |
|---|---|---|
| **TSAI-Lenz** | 可分离解：先由旋转轴角关系解 `R_X`（SVD），再解平移 | 已用 |
| **Park-Martin** | 把 AX=XB 写成李代数形式，用伴随矩阵求解 | 已用 |
| **Horaud-Dornaika** | 非线性优化形式 | 已用 |
| **Daniilidis 对偶四元数** | 把旋转+平移统一到对偶四元数，**同时**求解，避免误差传播 | 已用（但平移输入退化时会返回非正交阵） |
| **多方法一致簇投票** | 先筛掉非法旋转矩阵，再取互相在 1° 内的**最大一致簇**求平均 | 自研鲁棒化 |

> 只用陀螺，不需要加速度，也不需要 IMU 的绝对位置。

## 8. C3 平移外参（加速度计杠杆臂）

| 方法 | 原理 |
|---|---|
| **杠杆臂效应** | `R̈_WC·r = R_WI·a_meas + g_W − a_WC`，`r` 线性出现 → 最小二乘 |
| **R̈ 的解析构造** | `R̈ = R([ω_b]×² + [α_b]×)`，比直接对矩阵元素二次差分稳 |
| **Savitzky-Golay 平滑微分** | 局部多项式拟合，在保持高阶矩的同时求一阶/二阶导数（`savgol_filter`, window=9, order=3） |
| 中心差分求角速度 | `ω_W = log(R(t+h)R(t−h)ᵀ)/(2h)` |
| ⚠️ 当前结论 | 方程精确正确（真值残差 4e-15），但 `|b|` 只有 0.059 而 `|R_WI·a_meas|` = 9.82，**160:1 抵消** + `a_WC` 靠二阶数值微分 → 不可用 |

## 9. 验证方法

| 方法 | 指标 |
|---|---|
| **重投影误差** | 角点投影 RMS（px） |
| **标定残差** | train 上的平均重投影残差 |
| **运动一致性** | `A X` 与 `X B` 的相对旋转残差（度）。**必须用相对旋转**——绝对姿态比较会被"陀螺无绝对 yaw"毁掉 |
| **多方法离散度** | 四种手眼解法互相差角（实测 0.18°），本身就是"多次独立标定对比" |
| 交叉验证框架 | `keep_snapshots` + 数据切分，留作后续 |

## 10. 合成验证方法（元方法，最值得写进报告）

| 方法 | 原理 |
|---|---|
| **数字孪生** | 造一个真值完全已知的相机+IMU 刚体（**解析正弦叠加轨迹**，任意阶导数精确） |
| **逐方块正向投影 + 超采样渲染** | 黑方块四角用真值模型投影后 `fillPoly`，2~4× 超采样降采样得抗锯齿边缘。**比"纹理采样+线性插值"精度高一个量级** |
| **两层自检** | **点级**（正向投影出角点直接标定，验数学）+ **图像级**（渲染→检测→标定，验端到端）。因为**验证精度不可能超过测试夹具精度**，必须分层用各自的容差 |
| **收敛性实验** | 改变数据量（36→100→200 视图）看参数偏差是否收敛，用来区分"有限样本方差"与"系统偏差" |
| **畸变函数对比** | 不直接比 `k1/k2/k3`（高度相关、可互换），而是比 `1+k1r²+k2r⁴+k3r⁶` 在若干半径处的值 |

# 二、可以升级的高级方法

## A. 相机模型与内参

| 方法 | 一句话原理 | 成本 | 何时值得上 |
|---|---|---|---|
| **Kannala-Brandt 鱼眼模型** | 用 θ 的多项式代替 tan 投影，适合 FOV > 100° | 低 | 换广角/鱼眼镜头时 |
| **EUCM / Double Sphere** | 统一球面模型，单参数覆盖针孔到鱼眼 | 低 | 同上，且不用切换模型 |
| **卷帘快门（Rolling Shutter）模型** | 每行曝光时刻不同，给每行独立时间戳 | 高 | 用 CMOS 卷帘相机且运动快时。**本项目的 MV-CS020-10UC 是全局快门，不需要** |
| **不确定度 / 协方差估计** | `calibrateCameraExtended` 直接给参数标准差；或 Monte Carlo / Bootstrap | 低 | 报告里要写"这个内参的置信区间是多少"时，是加分项 |
| **可观测性驱动的视角选择** | 用 Fisher 信息矩阵挑最有信息量的姿态 | 中 | 想让 20 张图达到 50 张图的效果 |
| **ChArUco / AprilTag 阵列替代棋盘格** | 部分可见即可检测，且 ID 唯一 → 不会出现"角点顺序歧义" | 低 | 强烈建议。可顺便绕开平面 PnP 二义性 |

## B. 时间同步

| 方法 | 一句话原理 | 成本 | 何时值得上 |
|---|---|---|---|
| **硬件触发同步** | 相机 strobe/trigger 输出接 IMU 的外部中断脚，在曝光瞬间锁存计数器 | 中（要接线 + 固件支持） | **最可靠**，能直接消掉 τ 这个未知量。若 IMU 板有余量强烈推荐 |
| **互相关法** | 直接对 `‖ω_imu‖` 与相机角速度大小的**包络**做互相关，峰值位置即 τ | 低 | 作为当前角度匹配法的交叉验证 |
| **冲击/抖动对齐** | 猛地顿一下产生尖锐加速度尖峰，在 IMU 与图像序列里各找突变点 | 低 | 快速粗对齐，或在没有明显连续转动时 |
| **连续时间批量估计（Kalibr）** | 用 B-spline 表示连续时间轨迹，把 τ 作为待估参数与轨迹联合优化 | 高 | 想要工业级精度时的正解 |
| **DTW / 互信息对齐** | 不假设线性时间关系，允许非均匀偏移 | 中 | 时钟有漂移（非纯常量偏移）时 |

## C. 外参估计（本项目的主战场）

| 方法 | 一句话原理 | 成本 | 何时值得上 |
|---|---|---|---|
| **Kalibr 全批量优化** | 连续时间轨迹 + IMU 预积分 + 相机位姿 + 外参 + τ **联合**估计 | 高（2~3 天） | **最推荐**。且任务书本身认可"与成熟工具对比"作为验证方式 |
| **IMU 预积分（Forster et al.）** | 把两帧之间的 IMU 积分预计算成与状态无关的增量，避免优化中反复积分 | 中（要自己实现或上 GTSAM） | 想自己写批量优化时的标准组件 |
| **因子图 / GTSAM / Ceres** | 把标定写成图优化，自动求导 + 鲁棒核 + 边缘化 | 中 | 从"最小二乘"升级到"最大后验"的标准路径 |
| **在 SE(3) 上做优化（Sophus / manif）** | 旋转在流形上更新，避免欧拉角奇异与四元数归一化漂移 | 中 | 与上一条配合 |
| **鲁棒核（Huber / Cauchy）+ RANSAC / IRLS** | 抑制角点误检、PnP 异常帧 | 低 | **性价比最高**。当前实现里还没有 |
| **可观测性分析 / OC-EKF** | 分析哪些状态在什么运动下可观测，避免滤波器把不可观测量"估"成假值 | 高 | 写论文级报告，或做在线标定时 |
| **不变 EKF（Invariant EKF, Lie 群上的 EKF）** | 在 Lie 群上做误差状态定义，一致性显著优于普通 EKF | 高 | 做在线标定 |
| **在线/自标定（VINS-Mono / OpenVINS 风格）** | 用自然特征 + 运动约束在线估计外参，不需要标定板 | 高 | 想摆脱标定板，或做长期在线修正 |
| **联合标定 IMU 内参** | 同时估 scale、三轴非正交、轴间不对齐、g-sensitivity | 高 | 用廉价 MEMS 且要求高精度时 |
| **全局最优手眼标定（SDP 松弛）** | 把 AX=XB 松弛成半定规划，避免局部极小 | 中 | 数据质量差、局部解不稳时 |
| **平移的替代解法** | 见下 §C-1 | — | 解决当前 160:1 抵消问题 |

### C-1. 平移外参的三条替代路线（针对当前的 160:1 抵消）

| 路线 | 做法 | 为什么能解决 |
|---|---|---|
| **提高相机帧率** | 50~100 Hz。二阶微分噪声 ∝ 1/Δt²，5 倍帧率 → 噪声降 25 倍 | 直接压 `a_WC` 的噪声 |
| **避开显式微分** | 不用 `a_WC`，改用 **IMU 陀螺 + 相机角速度**构造等价方程；或把相机位姿写成 B-spline、解析求导 | 从根上绕开数值微分 |
| **IMU 预积分 + 批量优化** | 让杠杆臂由"整段数据"约束，而不是靠两帧加速度作差 | 不依赖单点信噪比，是 Kalibr 的做法 |

## D. 不确定度与验证

| 方法 | 一句话原理 | 成本 |
|---|---|---|
| **Allan 方差** | 由静止段长时数据分离出角度随机游走、零偏不稳定性、速率随机游走 → 正确填写噪声参数 | 低，必做 |
| **Monte Carlo / Bootstrap** | 重采样数据得到外参的经验分布与置信区间 | 低，报告加分 |
| **Cramér-Rao 下界** | 给出参数可达到的方差下界，回答"这个精度是不是已经到极限了" | 中 |
| **卡方检验 / 残差分析** | 判断残差是否只含噪声、是否有系统性偏差 | 低 |
| **k-fold / 留一交叉验证** | 框架已有，只需跑起来 | 低 |
| **与成熟工具对比** | 与 Kalibr / VINS-Mono / OpenVINS 的外参结果对比差角 | 中 |

## E. 采集与硬件

| 方法 | 一句话原理 | 成本 |
|---|---|---|
| **硬件触发线** | 见 §B，最彻底的时间同步方案 | 中 |
| **主动标定板（AprilTag 阵列）** | 抗遮挡、抗模糊、有唯一 ID | 低 |
| **运动激励优化** | 用 Fisher 信息 / 可观测性分析规划轨迹，最大化外参信息量 | 中，偏研究 |
| **多相机/多 IMU 冗余** | 用多个传感器互相约束，提升可观测性 | 高 |

# 三、优先级建议

按"性价比"排序（投入产出比从高到低）：

| 优先级 | 方法 | 理由 |
|---|---|---|
| **P0** | **鲁棒核 + RANSAC 剔除异常帧** | 几行代码，直接提升所有阶段的稳定性 |
| **P0** | **Allan 方差标定 IMU 噪声参数** | 配置文件里的噪声密度现在是占位值，报告里会被问 |
| **P0** | **ChArUco 替代棋盘格** | 顺手绕开平面 PnP 二义性，容错高得多 |
| **P1** | **提高相机帧率到 50~100 Hz + 剧烈旋转激励** | 解决当前唯一未通过的 t_IC |
| **P1** | **硬件触发同步** | 消掉 τ 这个未知量，时间对齐从"估计"变"测量" |
| **P1** | **Bootstrap / 协方差分析** | 报告里给出置信区间，答辩加分明显 |
| **P2** | **Kalibr 全批量优化** | 最可靠，且顺带满足"与成熟工具对比" |
| **P2** | **Ceres / GTSAM 因子图** | 从最小二乘升级到 MAP，工程能力的体现 |
| **P3** | 鱼眼模型 / 卷帘快门 / 在线自标定 / IEKF | 本任务用不上，但知道它们存在是加分项 |

# 四、答辩时可以主动提的三句话

1. **"我的时间对齐不依赖外参。"** —— 因为 `R_IC·ΔR_cam = ΔR_imu·R_IC` 是相似变换，旋转角必然相等，所以先用角度匹配解 τ，再解外参。这个顺序是有意设计的。

2. **"我的验证精度没有超过测试夹具的精度。"** —— 所以自检分两层：点级验数学、图像级验端到端，各自用匹配的容差。这是我能说清"0.082 px 的残差是渲染器的地板而不是算法的 bug"的原因。

3. **"平移外参我实现了但没收敛，原因是 160:1 的数值抵消。"** —— 主动讲清方法的边界，比给一个来路不明的数更可信。
