## 当前失败点

```
$ arv-camera-test-0.8
Looking for the first available camera
No camera found: Failed to bootstrap USB device '(null)-(null)-(null)-2BDFA3489519'

$ arv-test-0.8
Found 1 device
Failed to connect to 'U3V:MV-CS020-10UC'
```

**aravis 能发现设备**（型号与序列号都读对了），**但设备初始化握手失败**。

aravis 的 U3V bootstrap 流程是：打开 USB 设备 → 读设备的 GenICam XML 清单（manifest）
→ 写入临时文件 → 解析。失败可能发生在其中任一步。

## 待执行的两条诊断命令（需要用户在自己终端跑，第一条要 sudo 密码）

```bash
# 测试 1：用 root 跑，用于区分「权限细节问题」与「协议不兼容」
sudo arv-camera-test-0.8

# 测试 2：开 USB 调试日志，指出卡在哪一步（控制传输？读内存？写临时文件？）
ARV_DEBUG=usb arv-camera-test-0.8 2>&1 | head -40
```

判读方式：
- 若 **root 下成功** → 权限细节问题（如 libusb 对某些控制传输的权限要求），
  可通过补充 udev 规则（增加 `TAG+="uaccess"` 或放宽权限）解决
- 若 **root 下同样失败** → aravis 与海康 U3V 实现不兼容（常见于厂商自定义
  manifest 结构或特定控制请求），此时应改走海康 MVS SDK

## 备用方案：海康 MVS SDK（厂商官方路线）

若 aravis 不通，MVS SDK 是官方支持的可靠路线：

1. 从 [海康机器人官网](https://www.hikrobotics.com/cn/machinevision/service/download) 下载
   `MVS-x.x.x_x86_64_xxxxxxxx.tar.gz`（**需注册账号**）
2. 解压后运行 `sudo ./setup.sh` 安装到 `/opt/MVS`
3. 安装后提供 `MvProducerU3V.cti`（GenTL producer），
   本机已装好的 `harvesters 1.4.3` 即可直接使用：

```python
from harvesters.core import Harvester
h = Harvester()
h.add_file('/opt/MVS/lib/64/MvProducerU3V.cti')
h.update()
print(len(h.device_info_list), 'cameras')
```

**MVS 的额外优势**：提供硬件时间戳（对 Camera-IMU 标定精度有实质帮助），
而 aravis 路线通常只能用主机接收时刻近似。

## 最终结论（2026-09-10 23:27）

### 失败点已精确定位

```bash
$ ARV_DEBUG=all arv-camera-test-0.8
[UvDevice::new] GUID    = 2BDFA3489519
[UvDevice::new] Using control endpoint 1, interface 0
[UvDevice::new] Using data endpoint 3, interface 2
Get genicam
[UvDevice::read_memory] Try 1/5: command sending error: LIBUSB_ERROR_TIMEOUT
[UvDevice::read_memory] Try 2/5: command sending error: LIBUSB_ERROR_TIMEOUT
[UvDevice::read_memory] Try 3/5: command sending error: LIBUSB_ERROR_TIMEOUT
[UvDevice::read_memory] Try 4/5: command sending error: LIBUSB_ERROR_TIMEOUT
[UvDevice::read_memory] Try 5/5: command sending error: LIBUSB_ERROR_TIMEOUT
[UvDevice::_bootstrap] Error during memory read
```

**判读**：
- aravis 完整识别了设备（GUID、控制端点 1/接口 0、数据端点 3/接口 2 全对）
- 失败在**读取 GenICam 清单**这一步：向控制端点发"读内存"命令，**相机不应答**（5 次重试全部超时）
- 错误类型是 **TIMEOUT 而非 ACCESS** → **不是权限问题**

### 用 root 复现，排除权限

```bash
$ sudo arv-camera-test-0.8
No camera found: Failed to bootstrap USB device '(null)-(null)-(null)-2BDFA3489519'
```

**root 下同样失败** → 权限问题彻底排除，是 aravis 与相机的协议交互问题。

### 定性：aravis 的已知缺陷，不是本机配置问题

同类报告（其他品牌相机同样症状）：
- [aravis Issue #578 — UvDevice::_bootstrap Error during memory read（Teledyne Lumenera LT 系列）](https://github.com/AravisProject/aravis/issues/578)
- [aravis Issue #622 — usb3 multithreading causes mixup in libusb responses](https://github.com/AravisProject/aravis/issues/622)

Ubuntu 24.04 自带的 aravis 是 **0.8.30**，属于该系列较旧版本，对部分厂商 U3V 实现存在控制传输超时缺陷。
**结论：不值得为它投入时间**（要么自行编译新版 aravis，要么改走厂商 SDK）。

### 决策：改走海康 MVS SDK（官方路线）

理由：
1. 官方支持自家相机，兼容性风险最低
2. **提供硬件时间戳** —— 对 Camera-IMU 标定有实质精度收益（aravis 路线只能用主机接收时刻近似）
3. 附带完整的参数配置界面，锁定曝光/增益更方便

安装步骤：
1. 访问 [海康机器人下载中心](https://www.hikrobotics.com/cn/machinevision/service/download)（**需注册账号**）
2. 下载 `MVS-x.x.x_x86_64_xxxxxxxx.tar.gz`（Linux x86_64 版）
3. 解压后 `sudo ./setup.sh`，默认装到 `/opt/MVS`
4. 验证 Python 接口：

```python
import sys
sys.path.append('/opt/MVS/Samples/64/Python/MvImport')
from MvCameraControl_class import *   # 海康官方 Python 封装
```

或用 GenTL producer 配合本机已装好的 harvesters：

```python
from harvesters.core import Harvester
h = Harvester()
h.add_file('/opt/MVS/lib/64/MvProducerU3V.cti')
h.update()
print(len(h.device_info_list), 'cameras')
```
