## 技术要点备忘

### 平移外参攻坚（D4 核心）

**病根**：`a_WC` 靠对 PnP 位置做**数值二阶微分**，平面目标深度噪声被放大，淹没了 0.059 m/s² 的信号（160:1 抵消）。

**解法**：把 PnP 位姿序列拟合成 **B-spline**（`scipy.interpolate`），然后**解析求导**：

- 二阶导解析可得、光滑，不再有差分噪声放大；
- 代价远低于上 Ceres（约 1 天）；
- 直接打在病根上。

**若仍不收敛**，再考虑：IMU 预积分 + Ceres/GTSAM 全批量优化。

### ChArUco 为什么重要（D5）

不只是"更鲁棒"——**ChArUco 的角点带唯一 marker ID，对应关系物理唯一确定 → 平面 PnP 二义性从根上消失**。我们现在是被迫写消解逻辑才压住的。

## 不做什么（明确排除）

| 排除项 | 理由 |
|---|---|
| 主线重构到 ROS 2 | 花 1~2 天，精度零提升 |
| 硬件触发同步 | 你选择不动硬件；软件 τ 已够用 |
| 卷帘快门 / 鱼眼模型 | 本相机是全局快门、镜头非鱼眼 |
| 在线自标定 / IEKF | 离线标定场景用不上 |
| 追求"学术新方法" | 价值在工程实现与方法学，不在新原理 |
