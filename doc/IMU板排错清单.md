# IMU 板硬件排错清单

> 2026-09-10 · 针对当前现象：插电红灯瞬亮 → 三声提示音 → 之后红灯常亮 + 蜂鸣器持续响，
> 串口稳定输出 1 kHz 的 28 字节定长帧但**数据区恒为 0**，数据流 30 秒无中断。

## 已经排除的可能（附证据，不必再查）

| 假设 | 证据 | 结论 |
|---|---|---|
| 采集端丢包/配置错误 | 两次独立采集（8s / 15s / 30s）吞吐恒定 28,000 B/s，帧头计数与字节数完全吻合 | 排除 |
| 波特率不对 | USB CDC 虚拟串口波特率由固件决定，且字节流结构完全规整 | 排除 |
| 线材是充电线 | 设备能正常枚举成 STM32 Virtual ComPort | 排除 |
| 供电不足 | USB 正常枚举 + 持续 1 kHz 收发不掉线 | 排除 |
| USB/权限问题 | udev 规则已生效，`/dev/rw_imu` 可读写 | 排除 |
| MCU 死机 / 看门狗复位循环 | 30 秒内批次间隔中位 50.07 ms、最大 50.31 ms，**零中断**；帧内容指纹唯一 | 排除 |
| MCU 复位、时钟、USB 栈故障 | 三声上电提示音 + 稳定数据流 = 启动流程走完了 | 排除 |
| 协议理解错误 | 帧头 `ab cd 00 00 71 3d aa bf` 中 `00 00 71 3d` 按小端 float32 = 0.0588，含真实浮点常量 | 帧骨架是对的，排除 |

## 剩余假设与对应检查（按性价比排序）

### 检查 1：传感器模块能否重新插拔（最可能、最便宜）

**假设**：传感器与主板之间是排针/连接器/FPC 排线，接触不良或运输中松动。

**做法**：
1. 断电（拔掉 USB-C）
2. 找到传感器所在的小板或芯片，若是**插针/连接器**，小心拔下再插紧（注意别把引脚掰弯）
3. 若是**FPC 软排线**，打开卡扣重新插入，确认金手指完全到位、无氧化
4. 重新上电，观察那三声提示音之后是否还继续响

**成功标志**：提示音之后**安静下来**，串口数据区开始变化。
**验证命令**：`.venv/bin/python tools/analyze_frames.py --port /dev/rw_imu --seconds 5`
——出现「✅ 数据区在持续变化」即修复成功。

### 检查 2：认出传感器型号（决定后面所有排查方向）

**假设**：无法确定型号就无法判断是 SPI 还是 I2C、该初始化哪些寄存器、以及板子上的固件是否与该型号匹配。

**做法**（三选一）：
- **微距拍照**：手机贴到芯片上方 3-5 cm，开闪光灯，拍完在相册里放大念出那行字
- **斜光看丝印**：丝印是激光打标的，用手机手电筒**斜着**照，反光角度对时字会很清楚
- **数引脚**：实在看不清就数引脚数与封装大小，也能大幅缩小范围

**常见型号速查**：

| 型号 | 封装/引脚 | 接口 | 备注 |
|---|---|---|---|
| BMI088 | LGA-16 (3×4.5mm) | **SPI** | RoboMaster 开发板 C 型标配；社区有大量初始化踩坑记录 |
| ICM-42688-P | LGA-14 (2.5×3mm) | SPI / I2C | 常见于自制板 |
| MPU-6050 | QFN-24 (4×4mm) | **I2C** | 老型号，I2C 无应答是经典故障 |
| LSM6DS3 / LSM6DSO | LGA-14 | SPI / I2C | — |
| 维特 HWT101 / WT901 | 模块（带金属壳/PCB 小板） | **UART** | 若是模块，则主板通过串口读它，问题可能在板内串口链路 |
| ADIS16470 / ADIS16505 | 模块 | SPI | 工业级，成本高 |

**为什么这条最关键**：如果板子用的是 **BMI088**（RoboMaster 生态里最常见），
它的已知坑非常多——SPI 模式下加速度计与陀螺仪是**两个独立片选**，
固件里 CS 引脚配错、SPI 模式（CPOL/CPHA）选错、或者供电上电时序不对，
都会表现为「读取全 0 + 初始化失败报警」，与你现在的现象完全一致。
参见 [RoboMaster 开发板 C 型 IMU 驱动踩坑记录](https://sourcelizi.github.io/202204/bmi088-drv-setup/)。

### 检查 3：找烧录口与 BOOT 按钮（决定能不能自救）

**假设**：若板上有 SWD 排针（SWDIO/SWCLK/GND/3V3）或 BOOT0 按钮，就能自己重烧固件，
不必等别人给固件或换板。

**做法**：
- 找 4 个一排的排针，丝印常为 `SWD`/`SWDIO`/`SWCLK`/`DIO`/`CLK`/`GND`/`3V3`，或 `JTAG`
- 找板上的小按钮：`RESET`（复位）、`BOOT`/`BOOT0`（进系统 bootloader）
- 若同时有 BOOT0 按钮和 USB-C，则**可能不需要 ST-Link**：按住 BOOT0 再插 USB，
  芯片会进 ST 原厂 bootloader，可从 USB 直接烧录

**注意**：按住 BOOT0 插 USB 会让 CDC 端口消失，取而代之的是 DFU 设备（`0483:df11`）。
若你试了这一步，告诉我 `lsusb` 的输出，我能判断有没有进 DFU。

### 检查 4：有没有 QR 码 / 型号丝印 / 版本号

**假设**：这是战队的自制板，型号与资料可能要问电控组；但板上常印有版本号与二维码。

**做法**：把板子**所有**丝印念给我（两面都要），例如：
- 板名/版本：`RW-IMU-V1.2`、`RM-IMU-2026`
- 引脚标注：`SCL`/`SDA`/`SCK`/`MISO`/`MOSI`/`CS`
- 二维码：如果有，可能是资料链接

**引脚标注本身就是信息**：如果板上有 `SCL/SDA` 练到传感器，说明走 **I2C**；
如果是 `SCK/MISO/MOSI/CS`，说明走 **SPI**。这直接对应检查 2 的方向。

### 检查 5：万用表量传感器供电（有表再做）

**做法**：黑表笔接板子 GND，红表笔量传感器 VDD/VDDIO 引脚对地电压。
- **3.3V 左右** = 供电正常，问题在通信
- **0V** = 供电断了（LDO 损坏、走线断、或固件把供电脚拉低了）
- **明显低于 3.3V（如 1.8V/2.5V）** = 该型号要求的电压与板子不匹配

**注意**：探针别短路到相邻引脚，尤其别把 VDD 与 GND 短接。

## 与教练沟通时可以直接引用的事实

> 板子上电后红灯瞬亮、蜂鸣器先响三声（音调不同），随后红灯常亮且蜂鸣器持续响。
> 串口（STM32 CDC）稳定输出 1 kHz、28 字节定长帧、约 28 kB/s，30 秒内数据流零中断，
> 但**每一帧逐字节完全相同，数据区恒为 0**（8045 帧无一例外）。
> 帧头 `ab cd 00 00 71 3d aa bf` 中含小端 float32 = 0.0588 的真实常量，说明帧骨架正确。
> 判断：MCU/USB/时钟/主循环均正常，是传感器未被成功采样，固件进入报警态。
> 请问：这块板子正常工作时蜂鸣器是否也会响？有没有已知可用的固件可以重烧？

## 更新记录

### 2026-09-10 晚 · 新增事实与推论

**新事实**：
1. 传感器是**直接焊在主板上的**（不是插拔模块）→ "重新插拔"这条退路作废
2. 重新上电后**蜂鸣器依然持续响** → 故障可复现、非偶发
3. 板上有丝印 `YXC24000540021` 的器件

**对该丝印的判读**：`YXC` = 深圳扬兴科技（国内晶振大厂）；`2400` 为生产周期码（2024 年第 00 周）；
其余为料号/流水号。**这是晶振/谐振器，不是 IMU 传感器芯片。**
判据：YXC 是晶振厂商、不做 IMU；IMU 丝印一定是 InvenSense/TDK/Bosch/ST 的厂商码+型号；
晶振通常只有 2 或 4 脚、封装明显小于周围芯片。

**由此新增的硬件假设（可实测）**：

> IMU 芯片通常需要外部晶振（常见 32.768 kHz）作为内部时钟源。
> 该晶振不起振、虚焊，或固件把时钟源配置错误，会导致传感器初始化失败
> → 读回全 0 → 触发"红灯常亮 + 蜂鸣不停"。与当前现象完全吻合。

**对应实测**：
- 目视：微距拍摄晶振焊盘，查虚焊（焊锡发暗/有缝/爬锡不足）、裂纹、走线断裂
- 万用表：黑笔接 GND，红笔分别点晶振两脚对地电压。正常两脚电压不同且多在 0.5-2V；
  两脚同为 0V 或同为 3.3V 即基本判定未起振

**下一步需要的识别工作**：找出真正的 IMU —— 特征是**引脚最多/封装最大**的那颗芯片，
黑色塑料封装、四周一圈焊盘，丝印形如 `42688P` / `I088` / `6050` / `LSM6DS3`；
若带亮银色金属盖则为工业级 IMU。

**最高效的替代路径**：直接向教练/电控组索取该板的**传感器型号 + 原理图 + 可用固件**。

### 2026-09-10 深夜 · 协议逆向完成 + 外部资料搜索结论

**协议已完全逆向**（不再是猜测，有 8045 帧实测支撑）：

```
┌──────────── 28 字节定长帧，~1000 Hz ────────────┐
│ 头 4 字节    │ 数据 24 字节 = 6 × float32        │
│ ab cd 00 00  │ 陀螺 x/y/z  +  加速度 x/y/z        │
└──────────────┴──────────────────────────────────┘
头内另有一个小端 float32 = -1.33（疑似增益/数据率配置值）
```

依据：28 字节自相关一致率 100%；28 = 4 + 24，而 24 = 6 × float32 是 IMU 六轴最标准排法。
**当前数据区 6 个 float 全为 0 → 传感器从未被采样。**
